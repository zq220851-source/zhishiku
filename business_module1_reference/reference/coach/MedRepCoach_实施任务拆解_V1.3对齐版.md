| S1-07 | **双轨评分引擎** | 算法 | CommunicationRubric + MedicalEvidenceRubric | 分离实现；扣分能定位到具体回答与依据；**专业性严重错误不被流畅表达抵消**（AT12）；无证据→待复核而非硬给分 | 12 |
| S1-08 | **场景化报告** | 产品/算法 | AssessmentReport | 每条扣分附：原文片段 + 命中规则 ID + 改进方向；能指出具体问题而非只给分数 | 8 |
| S1-09 | **语音链路**（ASR→文本编排→LLM→TTS）| 工程 | 语音会话 | 可记录可审核文本；转写可由用户改正（AT16）| 10 |

## 7. 统一验收清单：V1.3 AT01–AT16

替换此前自拟的验收标准。每一项都标注对应任务。

| ID | 情形 | 必须得到的结果 | 对应任务 |
|---|---|---|---|

| AT02 | 目标专家与另一作者同名 | 展示待核实，不直接绑定论文 | S2-01 |
| AT03 | 预测问题数量需因任务变化 | 题目数量可变、每题有选择理由，**不能固定死 3 道** | S0-09, S1-03 |
| AT04 | 新日报摘要尚未审核 | 可内部阅读（若政策允许），不可作为正式知识评分依据 | S2-07 |
| AT05 | 同一审核知识包切换医生情绪 | 医学答案及合规边界不变，语言风格可变 | S1-05 |
| AT06 | 代表语音报告"医生好像不认可" | 标注主观推测；不固化为医生人格事实 | S1-11 |
| AT07 | 员工自述医生问题的原话记不清 | 保留"大意/不确定"；不生成虚假逐字对话 | S1-11 |
| AT08 | 上次练过研究终点，这次报告亚组证据 | 识别不同能力点并提出未覆盖候选，而非文字相似即命中 | S1-12 |
| AT09 | 无原预演计划却提交复盘 | 不计算"预测命中率"；可形成训练主题候选 | S1-12 |
| AT10 | 医学核验失败或审核拒绝 | 新内容无法发布，旧场景保持不变 | S1-13 |
| AT11 | 场景 V2 发布 | 显示"新增何考点、为何新增、谁审核"；支持恢复 V1 | S1-13 |
| AT12 | 专业内容错误但表述流畅 | 风险标记/不达标规则优先，**不被沟通高分简单抵消** | S1-07 |
| AT13 | 当天未采集到新研究 | 显示真实空态或历史回顾标签，不编造"今日最新" | S1-15 |
| AT14 | 文献撤稿或更正 | 找到受影响的知识卡、题目、日报条目并触发复核 | S2-05 |
| AT15 | 同一员工连续训练同一能力 | 记录独立于总分的能力轨迹；历史结果带版本和难度 | S1-14 |
| AT16 | ASR 失误导致误判 | 用户可改正转写，重算评分或转人工复核 | S1-09 |
