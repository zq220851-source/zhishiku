## 硬性禁止

1. **禁止 web 搜索**补充法规文号、指南版本号、临床数据、药品名、公司名。
2. **禁止凭记忆写**任何事实性表述。
3. 语料查不到 → 写「语料未覆盖」并说明缺什么。**这是合格交付，不是失败。**
4. 课件内容里若含**演示道具**（如 `[A36 S97]` 双氢可待因复方制剂、`[A36 S106]` 智灵通DHA、`[A75 S128]` Ａ产品），**严禁当作真实药品知识使用**。
5. 课件内容里若含**违规灰色手法**（回扣/临床费/统方/二次公关等，见 `corpus_assets.jsonl` 的 `gray_area: true`），**只能作为识别对象**，不得写成推荐做法或高分锚点。
