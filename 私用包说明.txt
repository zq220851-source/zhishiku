MedRepCoach 含 API Key 私用包

已包含当前 .env.local 的语音及大模型服务配置。不要用 .env.example 覆盖它。
本 ZIP 未加密，请勿公开分享或上传到公开仓库。

启动：
1. 解压后进入 MedRepCoach 目录。
2. 安装 Node.js 24、Python 3.11 或更新版本。
3. 执行 python3 scripts/setup_local.py
4. 执行 python3 scripts/run_local.py
5. 使用 Chrome 打开 http://localhost:5190/

首次启动会生成新的本机体验账号，见解压目录中的“本机体验说明.txt”。
本包未包含旧本机账号、运行数据库或业务记录。当前实现范围及未验收项见 docs/06_本轮实现与验收.md。
