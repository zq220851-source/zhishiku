# MedRep Coach｜核心判断实验台（独立静态前端）

1. 将 `preview` 文件夹完整解压到本地。
2. 双击 `index.html` 即可使用。它只加载相邻的 `app.bundle.js`，无网络服务、账户、模型密钥、后端接口或额外依赖。
3. 点击左侧 9 个虚构案例查看输入、业务判断和选题比较；点击「运行全部 9 项」查看规则是否符合预期。

**重要**：这不是语音识别/AI 口语分析测试；本页直接使用预先构造的结构化语义输入，真实运行的是 `lib/decision-engine.ts` 和 `lib/strategy.ts` 中的共享内容/策略决策逻辑。用例的自然口述只是帮助人理解测试场景，不是模型实际抽取结果。

`app.bundle.js` 是从项目 TypeScript 核心代码构建的浏览器包，不包含医学知识库、真实 API Key、真实员工资料或后端服务。

如需在完整 Next.js 应用中测试自然口述及 L1 训练：在项目根目录 `npm install`，在 `module2/` 参照 `.env.example` 配置仅用于虚构测试的模型，然后 `npm run dev`，浏览器访问 http://127.0.0.1:3202 。模块 2 主页面已加入「4. 测试实验台」页签；此处的静态测试台与主页面使用同一个决策源代码。
