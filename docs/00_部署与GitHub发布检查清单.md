# MedRep Coach：私有 GitHub → 飞书工作台上线核对表

> **当前仅完成代码准备与本地验证，尚未提交到用户 GitHub，也尚未连接用户飞书。** 不应在任何凭证和 HTTPS 环境未确认前宣称线上可用。

## 1. 第一次上 GitHub

- [ ] 审查第三方素材、内部资料、医学知识来源和使用许可。不得将私有医学知识库、员工数据、模型密钥提交 GitHub。
- [ ] 用户将 GitHub 连接到 ChatGPT；指定已存在仓库 URL，或明确授权新建 `medrep-coach` **私有仓库**。
- [ ] 确认仓库属于用户/公司；首次推送至新分支 `integration/feishu-h5`，经 PR 审核后合并默认分支。**不要强推覆盖用户已有代码。**
- [ ] GitHub Actions `Source security and integration tests` 通过。Android/iOS 工作流只在有需要时手动触发。
- [ ] 公开仓库需要另行评估开源许可证和素材版权，本交付默认私有。

## 2. 每家企业各自部署

- [ ] 准备本企业 HTTPS 网址、服务器、PostgreSQL 和备份；对中国大陆公网业务完成适用备案。
- [ ] 创建自己的飞书企业自建应用，设置网页应用移动/桌面主页地址为 `https://你企业合法域名/`，设置可信域名、可用人员范围和审核发布。
- [ ] 仅前端构建环境放 `VITE_FEISHU_APP_ID`；`FEISHU_APP_SECRET`、模型密钥、语音服务密钥只放服务器密钥管理。
- [ ] 首位管理员由管理员 CLI 建立；按企业组织逐个创建或审核绑定员工的 `feishu_open_id`。未绑定员工不允许自动注册。
- [ ] `mobile_app` 运行 `npm install && npm run build`，由 Caddy 通过同一 HTTPS 域名提供静态 H5 和 `/v1/mobile/*` 反向代理。
- [ ] 仅开放 HTTPS 网关，不直接公开数据库、模块一 Cookie API 或 `/v1/internal/*`。
- [ ] 模块一 FastAPI 必须与平台在受限内部网络中可达，配合独立员工身份映射；验证 `learn` 与 `visit` 两条流程。
- [ ] 在真实飞书 Android/iPhone 上测试免登录、退出/禁用账号、访前预测冻结、医生追问、复练和麦克风授权。

## 3. **不能跳过的阻断条件**

- 未备案或不满足适用监管要求：不对外开放国内服务。
- PostgreSQL/服务器尚未验证：不能承诺真实数据安全持久化。
- 未接入真实大模型/百炼语音/LiveKit：不能承诺真实语音陪练已可用。
- 模块二仍有演示身份/审核权限：不能将该模块对企业员工正式开放写操作。
- 医学内容、外部素材未经审查：不作为公开源码或者正式医学培训材料分发。
