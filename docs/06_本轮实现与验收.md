使用用户提供的服务端配置，模型为 deepseek-v4-pro。所有测试内容均为本机模拟练习，不是实际拜访报告。

1. 百炼 TTS 成功返回 PCM，ASR 成功识别合成中文音频；模型网关 HTTP 200 并返回非空文本。
2. 完整模拟语音练习出现 ready → speaking → listening → interrupt → thinking → run → speaking → paused，识别原话和医生回复均保存；返回音频超过 1 MB。
3. 课程练习结束后获得 3 项观察，medical_accuracy 为 NA；可读 17 个资料段；补练结果关联原复盘；复练增加轮次，旧转写与评价保留在 attempts 历史中。
4. 访前准备生成 3 个候选重点；冻结前可试练；冻结预算为 1；重读一致；再次冻结返回 409。
5. 模拟复盘 A 分析成功；更正原文后旧资产立即失效，重算恢复 CURRENT。模拟资产包含个人能力 1 项、预测经验 2 项、知识覆盖 2 项；实际交流计数仍为 0。
6. 实时日报返回 2026-11-01 的采集日期、30 天窗口、4 条行业内容和逐来源状态。未选择个人方向时学习列表为空，不自动编造负责产品。
7. 身份认证后的目录可访问 71 门课程和 20 个产品选项。

关闭不必要的推理输出后，结构化复盘请求由超时恢复为成功；这是本机模型配置，可在 .env.local 中调整。
