# 飞书 H5 客户端内登录：验收操作与结果判定

## 真实路径

1. 员工进入企业飞书工作台中的 MedRep Coach 网页应用。
2. H5 加载 `VITE_FEISHU_APP_ID`，经 `tt.requestAccess` 获得一次性 `code`。
3. 同源 HTTPS POST `/v1/mobile/auth/feishu`，只传一次性 code。后端换取身份，只允许本租户已开通并绑定 `open_id` 的员工登录。
4. 后端签发内存态 Bearer 会话；所有 `/v1/mobile/*` 业务请求必须校验员工身份。
5. 模块一：**学课 → 学课表达练习**（`learn`）与 **访前资料 → 候选预测 → 冻结 → 模拟实战 → 反馈与复练**（`visit`）都可访问且数据互不串用。

## 验收用例

| 编号 | 操作 | 预期 |
|---|---|---|
| F01 | 在飞书工作台打开 URL | H5 页面可加载，无 JS SDK 错误 |
| F02 | 已绑定员工免登 | 服务端验证 code 后建立当前员工会话 |
| F03 | 未绑定员工免登 | 拒绝（403），不自动开户 |
| F04 | 重用过期授权码 | 验证失败（401） |
| F05 | 员工 A 访问员工 B 的准备单 | 拒绝，不泄露记录 |
| F06 | 课程中点击表达练习 | 实际调用模块一 `learn` |
| F07 | 访前资料/预测冻结后点击模拟实战 | 实际调用模块一 `visit`，进入医生多轮追问 |
| F08 | 结束实战、查看反馈、查看资料、重练 | 真实模块一接口成功，无假数据 |
| F09 | Android/iPhone 权限检查 | 实测麦克风、实时语音功能（未接线则标记未完成） |
| F10 | 退出、禁用员工、过期会话 | 旧会话不可继续调用 API |

## 仍需用户/企业管理员授权

- 飞书开发者后台创建自建应用、配置主页及可信域名、开通权限并发布/审核。
- 服务器与合法 HTTPS 域名、数据库、合法存储和备案。
- 飞书 App ID 可用于前端；App Secret 必须仅通过服务器环境变量/密钥管理配置，不能贴到聊天中。
