# 演示与企业分发：推荐双通道

## 我们的演示

- 将本仓库部署在我们名下的 HTTPS 演示环境，数据库只存虚构测试员工和虚构演示数据。
- 用**我们自己的飞书企业**创建 `MedRep Coach Demo` 企业自建网页应用。配置移动端主页、可信域名与用户范围。通过飞书工作台打开。
- 实际模型调用必须走后端保密钥，设置调用预算、并发限制、审计日志；医学场景保留验证与人工审核标识。
- 未经验证的 iOS/Android 实时语音不得对外承诺已经可用。

## 企业自行使用

- 正式公开前决定源码许可与医学资料许可。**不要把公司的课程资料或业务资产因误公开而变成可免费下载。**
- 用 GitHub Release 标记版本；保留升级指南、数据迁移说明、变更日志。
- 不同企业各自建立飞书自建应用，使用自己的 HTTPS H5 站点。
- 如果希望企业不部署服务器、点击安装即可使用，则需要额外开发**多租户托管 SaaS**，不能只靠 GitHub/飞书 H5 实现。

## GitHub 私有仓库上传（用户授权下执行）

```bash
# 在 GitHub 网页上创建 PRIVATE 仓库 medrep-coach，不要勾选自动创建 README
cd medrep-coach
python3 scripts/prepublish_check.py
# 先人工审查差异与文件内容，再操作：
git init
git add .
git status --short
git commit -m 'Initial MedRep Coach H5 self-host candidate'
git branch -M main
git remote add origin https://github.com/YOUR_ORG/medrep-coach.git
git push -u origin main
```

需在你授权的本地电脑或 GitHub 环境执行，**当前交付包未上传到 GitHub**。公共发布前，必须先看 `03_公开发布前审查.md`，并自行确定许可证和商业授权策略。
